How to use FocusFlow

Every blocking mode, what the app locks while a block runs, how the PINs work, and how to plan subtasks. The same text as the in-app help screen.

In short: FocusFlow is a free, open-source Android app blocker (Android 10 or newer, no root). You can block distraction six ways — Focus Mode, Standalone Block, Keyword Blocker, VPN Network Protection, Group Schedules and Home Launcher — and the app locks changes that would weaken a block while it runs. For a timed block right now, start with Standalone Block (Focus tab).

What blocking modes does FocusFlow have?

FocusFlow has six ways to block distraction. They can be combined.

ModeWhat it does
Focus ModeFocus Mode is connected to a task. Start a task from the Focus tab, choose the apps allowed during that session, and start Focus Mode when you are ready to work.
Standalone BlockStandalone Block does not need a task. Open it from the Focus tab, choose the apps you want blocked, and set how long the block should last. It is the best choice when you want a timed block right now.
Keyword BlockerKeyword Blocker watches visible text, searches, and URLs for words you add. When a blocked word appears, FocusFlow sends the current app home. It works independently of an app list or focus session.
VPN Network ProtectionVPN protection cuts internet access for the apps you select. Use the VPN list for always-on network blocking, or add VPN protection to a standalone block or group schedule when that block is running.
Group SchedulesGroup schedules are recurring block windows. Add several apps to one window, choose the days and times, and let the same group run automatically every week. A schedule can also include VPN protection.
Home LauncherHome Launcher replaces your home screen with a focused launcher. Choose Classic or Glassy, select the apps shown in the drawer, and use launcher protections to make switching away harder during a standalone block.

How do I set up a strong block?

  1. Start with Standalone Block

    Go to the Focus tab, choose Standalone Block, select every app you want blocked, and set the time. This works without creating a task and stays active until the timer ends.

  2. Grant the important permissions first

    Open Settings → Permissions and grant Accessibility and Usage Access so FocusFlow can detect and stop blocked apps. Grant Device Admin as an additional layer before starting a serious standalone block; it adds resistance to force-stop and uninstall escape paths, but it is not a magic guarantee by itself. Stuck? See permissions troubleshooting.

  3. Turn on Protect system controls

    In the Defense tab, enable Protect system controls before the block starts. This protects system screens and navigation paths that could otherwise be used to weaken an active block.

  4. Add the extra layers you need

    From the Defense tab, enable Network Protection, launcher protections, aversion deterrents, Shorts/Reels blocking, or other safeguards. These layers work alongside the app block instead of replacing it.

  5. Know what absolute means

    FocusFlow blocks the apps and escape routes you configured. Keep emergency, phone, launcher, and other protected system apps available, and do not treat any Android protection as a substitute for emergency access.

What can I change while a block is running?

WhereRule
Always-On and VPN listsYou can add more apps while protection is running. Removing apps from either list is locked during an active Focus Mode or Standalone Block so the block cannot be weakened halfway through.
Keyword BlockerYou can add keywords without a password. Removing keywords or clearing the list is protected, and an active standalone block can lock those removals completely.
Group schedulesYou can add a new schedule without a PIN. When Defense PIN protection is enabled, editing a schedule, removing apps, disabling a window or its VPN protection, shortening its duration, or deleting it can require the Defense PIN. An active Standalone Block can also prevent deleting a schedule.

Why FocusFlow locks changes. A protection tool is only useful if it cannot be quietly weakened after it starts. FocusFlow allows safer additions, but guards removals, shorter windows, disabled toggles, and other changes that reduce protection.

How do the PINs work?

PINWhat it guards
Focus Session PINWhen configured, it is required to stop an active Focus Mode session early or turn off the full-duration rule. Without a PIN, stopping still requires the normal confirmation.
Defense PINGuards actions that weaken protection: disabling protected Defense toggles, removing apps from Always-On or VPN lists, removing keywords, and changing protected settings.
Adding is easier on purposeAdding apps to Always-On, adding apps to the VPN list, and adding keywords do not normally require a PIN. The protection is aimed at removal and weakening, not at stopping you from adding another safeguard.

Set both before a serious block. Open Defense → PIN Protection to configure the Focus Session PIN and Defense PIN. Keep them somewhere safe; forgetting them can leave a protection active until its normal expiry or until the correct recovery path is used.

What do the other toggles do?

ToggleWhat it does
Protect system controlsBlocks or redirects sensitive system-control paths such as the power menu, Settings, and other escape routes. It cannot be turned off while Focus Mode or Standalone Block is active.
Network Protection and self-healNetwork Protection uses the local VPN to cut internet access for selected apps. Self-heal watches the VPN and helps restore it if Android disconnects it. Android VPN permission is required.
Launcher protectionsHome Launcher protections can lock the default launcher choice, protect against uninstall attempts, and keep FocusFlow in control during a standalone block. Configure them from Home Launcher or the Defense tab.
Aversion deterrentsVibration, screen dimming, and sound alerts react when a blocked app opens. They are optional and reinforce the block; they do not replace Accessibility, Usage Access, or the block list.
Content and Focus settingsShorts/Reels blocking, Auto-enable Focus Mode, and keeping focus active for the full task duration change how enforcement behaves. Enable only the layers that match your routine, then test them before starting a long block. To block one screen in any other app, see Custom Screen Rules.

How do subtasks and exercise plans work?

  1. Group a session into one task

    A task can contain several subtasks, such as exercises in one workout. In task details, tap a checkbox to mark an item done or tap its row to open the instructions, steps, and goal.

  2. Track sets and rest

    Set goals show sets and reps, including ranges such as 3 × 6–10. In imported goals, reps is the low end and repsMax is the high end. Tap each set circle as you finish it; the optional rest timer starts between sets and can be turned off.

  3. Add a photo

    Open a subtask or step menu to add, replace, or remove a photo. Items that still need a picture show “Photo needed” with a short description. Pictures are resized and stored privately on this device.

  4. Complete the task when you are ready

    Finishing every subtask does not complete the scheduled task automatically. Use the separate Complete task action when you are ready; you can also complete a task with unfinished subtasks.

  5. Import a task plan

    A .focusflow file is normally plain JSON. Pictures are described as photo slots that you attach later. See the .focusflow file format.

Quick answers

How do I block apps on Android with FocusFlow?

Open the Focus tab, choose Standalone Block, select the apps you want blocked and set how long the block should last. Grant Accessibility and Usage Access first (Settings → Permissions) so FocusFlow can detect and stop blocked apps.

What is the difference between Focus Mode and Standalone Block?

Focus Mode is connected to a task: you start a task and choose the apps allowed during that session. Standalone Block needs no task: you choose the apps to block and a duration, which suits a timed block right now.

Can I remove apps from the block list while a block is running?

No. Removing apps from the Always-On or VPN lists is locked during an active Focus Mode or Standalone Block, so the block cannot be weakened halfway through. You can still add more apps.

What is the difference between the Focus Session PIN and the Defense PIN?

The Focus Session PIN is required to stop an active Focus Mode session early. The Defense PIN guards actions that weaken protection, such as turning off protected Defense toggles, removing apps from the Always-On or VPN lists, or removing keywords. Both are set under Defense → PIN Protection.

How do I block YouTube Shorts or Instagram Reels?

Turn on Shorts/Reels blocking in the Defense tab. To block one particular screen inside any other app, use Custom Screen Rules.

Can FocusFlow block certain words or websites?

Keyword Blocker watches visible text, searches and URLs for words you add. When a blocked word appears, FocusFlow sends the current app home. It works independently of an app list or focus session.

What is Home Launcher?

Home Launcher replaces your home screen with a focused launcher. You choose a Classic or Glassy look, pick the apps shown in the drawer, and can turn on launcher protections to make switching away harder during a standalone block.

Where is the How to use screen inside the app?

Open the side menu and tap How to use. This page contains the same guidance.

Is FocusFlow free, and does it need root?

FocusFlow is free, has no ads and is open source (AGPL-3.0). It does not need root and runs on Android 10 or newer.

Does FocusFlow guarantee that emergency calls stay reachable?

No. FocusFlow keeps emergency, phone, launcher and other protected system apps available, but it makes no guarantee about emergency access. It is a focus tool, not a safety system.
