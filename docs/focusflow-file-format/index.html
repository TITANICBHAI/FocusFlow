The .focusflow file format

How FocusFlow task backups are structured, what the importer accepts, and how to have an AI assistant write one for you. Matches the in-app File guide.

A .focusflow file is either a plain UTF-8 JSON document or a ZIP bundle containing a JSON manifest and image files. It carries portable task and settings data that FocusFlow can validate and restore. This page matches the in-app File guide.

File facts

PropertyValue
Extension.focusflow
KindFocusFlowBackupV1
Version1 for task-only files; 2 when subtasks or image assets are included. The importer accepts versions 1 and 2 and rejects other values.
EncodingUTF-8 JSON
MIME typeapplication/octet-stream

A backup is not a snapshot of the live device. Active Focus sessions, current enforcement state, PIN/device security state, and live alarms are not restored.

Envelope

The smallest valid file (version 1, one task, empty settings):

{
  "kind": "FocusFlowBackupV1",
  "version": 1,
  "exportedAt": "2025-01-15T10:00:00.000Z",
  "platform": { "os": "android" },
  "settings": {},
  "tasks": [{
    "id": "weekly-review",
    "title": "Weekly review",
    "description": "",
    "startTime": "2025-01-15T09:00:00.000Z",
    "endTime": "2025-01-15T09:50:00.000Z",
    "durationMinutes": 50,
    "status": "completed",
    "priority": "medium",
    "tags": ["planning"],
    "reminders": [],
    "color": "#6366f1",
    "focusMode": false,
    "createdAt": "2025-01-14T10:00:00.000Z",
    "updatedAt": "2025-01-15T10:00:00.000Z"
  }]
}

summary and presetSections are informational only; the importer recalculates taskCount from the tasks and does not activate any behaviour from presetSections.

Task fields

FieldRule
idRequired, unique string identifier (at most 128 characters).
titleRequired; cannot be blank (at most 1,000 characters).
descriptionOptional text; use an empty string if none was requested.
startTime / endTimeISO-8601 instants with an offset; endTime must be later than startTime.
durationMinutesInteger number of minutes, equal to the elapsed time.
statusscheduled, active, completed, skipped, or overdue.
prioritylow, medium, high, or critical.
tagsArray of strings; an empty array is valid.
remindersReminders are objects, not plain integer offsets. The app preserves this array opaquely; Android notification slots are derived from task times instead. Generated files use [].
colorRequired string; #6366f1 if none was requested.
focusModeRequired boolean; false unless Focus mode was requested.
focusAllowedPackagesMissing or null means use the global allow-list. An explicit empty array means all apps are allowed for this task. A non-empty array names the task-specific apps (exact Android package IDs).
createdAt / updatedAtISO-8601 instants; canonical generated files use UTC Z.
subtasksOptional array for the parts of one session.

Subtasks and goals

Use subtasks when one task is a session made of parts you tick off one by one, such as the exercises in a workout. Files with subtasks use version 2.

FieldRule
id / titleEach subtask needs a unique ID (1–64 letters, digits, _ or -) and a title (1–200 characters).
subtitleOptional short supporting text, at most 120 characters.
layoutOptional steps or overview; if omitted, steps are used when steps exist, otherwise overview.
explanationOptional plain text, at most 4,000 characters. Blank lines start paragraphs; lines beginning with - are bullets.
stepsOptional list of up to 30 steps. Each step needs text (up to 1,500 characters); title and photo are optional.
tips / avoidOptional arrays of up to 10 strings each, up to 300 characters per string.
progressDo not include done or setsDone in generated files; progress belongs to the app.

Goal kinds

KindFields
setssets (1–99) plus reps (1–9,999) or seconds (1–86,400); repsMax is optional for rep ranges and must be at least reps; optional restSeconds (0–3,600), weightKg (0–1,000), and label.
reps / durationreps needs reps (1–9,999) and may include repsMax; duration needs seconds (1–86,400).
distancemeters from 1 to 1,000,000.
textlabel is required and can be at most 80 characters.

Pictures: describe them, FocusFlow attaches them

Do not put image data in the file. Add a photo slot where a picture would help: brief (one sentence, at most 300 characters), an optional url (a direct https link to a JPEG, PNG or WebP file) and optional alt. FocusFlow shows Photo needed until a picture is attached; a link is only downloaded after you confirm, the file is checked to be a real JPEG/PNG/WebP of at most 6 MiB, and a private copy is stored on the phone.

Only if you have real image files, use a ZIP bundle: a real ZIP named *.focusflow with manifest.json at the root and images under assets/ (WebP, PNG or JPEG, long edge at most 1280 px, each at most 1 MiB, at most 300 images, ZIP at most 64 MiB). Never invent image data.

Settings: only portable ones

Only portable settings are restored. Live toggles, onboarding/privacy state, PIN state and device-only resources stay local; omitted fields do not reset local values. Task-only prompts set settings to {}.

GroupFields
Focus preferencesdarkMode, defaultDuration, pomodoroDuration, pomodoroBreak, keepFocusActiveUntilTaskEnd, autoRescheduleEnabled
App listsallowedInFocus, alwaysOnPackages, alwaysOnVpnPackages, focusToolPackages, launcherHiddenPackages, launcherDockPackages
Blocking and schedulesblockedWords, greyoutSchedule, recurringBlockSchedules, dailyAllowanceEntries (keep greyout windows and recurring schedules separate; they are different data)
Presets and profileallowedAppPresets, blockPresets, userProfile, launcherTheme
ProtectionprotectionMode and focusMirrorVpnEnabled. A backup cannot override FocusFlow’s system-protected package list.
Custom screen rulescustomScreenRules: a list of rules in the same shape as the rules export file (name, packageName, enabled, matchMode, matchers). It is left out when there are no rules. Restoring only adds: your own rules stay as they are, a rule you already have is skipped, every added rule gets a new id, the limit of 30 rules applies, and unsafe rules are skipped. enabled is kept.

How import works

ChoiceBehaviour
MergeKeeps existing tasks and adds tasks with new IDs. A same-ID task is skipped, except that the review screen can opt in to adding subtasks to matching tasks that have none. Existing subtasks are never overwritten.
Replace tasksReplaces task rows only; it does not mean replace everything. The app refuses task replacement while a Focus session is active.
SettingsThe Merge/Replace choice applies to tasks. Portable settings follow field-specific rules; omitted settings and device-local values stay local. Custom screen rules are always merged, even with Replace tasks.
Opening from FilesOpening a .focusflow file from Files or another app follows the same flow: validate, review, confirm, then restore. Past-due scheduled tasks are imported as skipped.

Have an AI assistant write the file

Copy the prompt below into any AI assistant, then describe your tasks, dates, time zone and constraints at the end. It can group one session into a task with subtasks and describe each picture as a photo slot, without touching FocusFlow’s other features or global settings. FocusFlow shows an import review before applying anything.

⬇ Task-backup prompt (.txt)   Open as plain text

The same prompt is available in the app: Settings → FocusFlow File Guide → Copy task-backup prompt. For AI agents: the prompt is self-contained; follow it exactly and never invent package IDs, links or image data.

Limits

LimitValue
JSON file sizeAt most 8 MiB, no more than 20,000 tasks, nesting depth at most 12, at most 2,000,000 JSON nodes.
SubtasksAt most 50 per task; all subtasks of one task together stay under 96 KB of JSON.
Tags / remindersUp to 100 tags per task (100 characters each); up to 100 reminders per task.
Images in JSONAt most 200 assets; 4 MiB of decoded image data in total; generated images should be 100 KB or less each and 3 MiB combined.
Package listsAt most 5,000 package IDs per list; each at most 255 characters.
