    02 / From file to FocusFlow

    Three calm steps to import.

    The file is ordinary JSON with a .focusflow extension. Keep a copy somewhere you can find it, then use FocusFlow’s import flow on your Android device.

    01 — CREATE

    Make your schedule

    Fill in the task details above. Use local start times, add reminders if useful, and leave Focus Mode off unless you want to configure its app allow-list.

    02 — SAVE

    Validate & download

    Choose Validate, fix any errors, then copy the JSON or download the .focusflow file. Store the download where it’s easy to select on your phone.

    03 — IMPORT

    Select it in FocusFlow

    In FocusFlow on Android, open Settings → Import Backup and select your saved file.

    What import does: FocusFlow merges imported settings with the destination’s current settings. By default, existing task rows stay in place; tasks whose IDs already exist are skipped. A task-only file with "settings": {} does not change destination settings. Import is not an automatic “replace everything” operation.
    Settings are merged

    Only settings present in a file can affect matching destination values. This builder keeps settings empty for ordinary schedules.

    Existing tasks remain

    With the default import behavior, matching task IDs are skipped and other existing task rows are kept.

    Data, not live device state

    Task/reminder records travel in the file. Active sessions and live enforcement state do not; FocusFlow schedules alarms locally from imported scheduled tasks.

    03 / Developer reference

    The useful bits of V1.

    Generated files use the current Task shape and the envelope emitted by FocusFlow’s backup service. Keep task IDs unique and timestamps explicit.

    Envelope

    kind
    Required string: FocusFlowBackupV1.
    version
    Integer 1 for generated files.
    exportedAt
    ISO timestamp in UTC.
    exportedAtHuman
    Human-readable export time.
    platform
    Informational object, for example {"os":"web"}.
    settings
    Required object. Keep {} for task-only files.
    tasks
    Required array of Task objects.
    presetSections
    Descriptive inventory; does not activate behavior.
    summary
    Derived counts; taskCount equals tasks.length.
    appVersion
    Optional diagnostic metadata; omit if unknown.

    Task & reminder fields

    Canonical generated tasks include every core field. description is optional in the TypeScript type; this builder always emits it.

    id / title
    Unique task ID and a non-empty title.
    startTime / endTime
    ISO UTC instants. Duration is whole minutes and matches the interval.
    durationMinutes
    Integer duration; status is scheduled.
    priority
    low, medium, high, or critical.
    tags / color
    String array and color string.
    reminders
    Array of objects: id, taskId, integer offsetMinutes, and type.
    focusMode
    Boolean; generated false unless Focus Mode is enabled in the builder.
    focusAllowedPackages
    Omitted by this builder; tasks inherit the global settings allow-list.
    createdAt / updatedAt
    ISO UTC instants.

    Reminder types

    Offsets are relative to the task start. This builder assigns the type from the offset’s sign:

    { "id": "reminder-id",
  "taskId": "task-id",
  "offsetMinutes": -10,
  "type": "pre-start" }

    pre-start is negative, at-start is zero, and post-start is positive. The reminder record is persistent data, not a serialized Android alarm registration.

    Time & Focus Mode

    The builder reads your browser’s local datetime input and converts it to a UTC ISO timestamp ending in Z. It computes endTime from the start and integer duration.

    Focus Mode is off by default. When enabled here, a non-empty settings.allowedInFocus list is required and tasks inherit that global list—no per-task override is written.

    Keep ordinary task-only files at settings: {} so import leaves destination settings alone.

    04 / Shape of a file

    Small on purpose.

    The builder above produces this envelope plus complete task records. Dates and IDs below are illustrative; use the live builder for current values.

    Complete task-only example

    {
  "kind": "FocusFlowBackupV1",
  "version": 1,
  "exportedAt": "2099-09-01T07:00:00.000Z",
  "exportedAtHuman": "9/1/2099, 7:00:00 AM",
  "platform": { "os": "web" },
  "settings": {},
  "tasks": [{
    "id": "task-example-01",
    "title": "Focused reading",
    "description": "Read one chapter.",
    "startTime": "2099-09-01T08:00:00.000Z",
    "endTime": "2099-09-01T08:45:00.000Z",
    "durationMinutes": 45,
    "status": "scheduled",
    "priority": "medium",
    "tags": ["reading"],
    "reminders": [{
      "id": "reminder-example-01",
      "taskId": "task-example-01",
      "offsetMinutes": -10,
      "type": "pre-start"
    }],
    "color": "#557b68",
    "focusMode": false,
    "createdAt": "2099-08-31T12:00:00.000Z",
    "updatedAt": "2099-08-31T12:00:00.000Z"
  }],
  "presetSections": [],
  "summary": {
    "taskCount": 1,
    "blockedWordCount": 0,
    "greyoutWindowCount": 0,
    "dailyAllowanceCount": 0
  }
}

    This is valid JSON, but its dates are illustrative. Use the builder above to create a schedule with current timestamps.

    Portability boundary

    FocusFlow exports portable persistent data. The exporter deliberately omits device-local and live enforcement state; active sessions, current alarms and device runtime state are not a part of a .focusflow file.

    Import requires a JSON object with kind: "FocusFlowBackupV1", a settings object and a tasks array. The envelope’s summary is helpful metadata, not the task source of truth.
