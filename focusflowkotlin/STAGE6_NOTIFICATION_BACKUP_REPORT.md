## Backup compatibility invariants

- Exported files remain `.focusflow` JSON with `kind: "FocusFlowBackupV1"` and `version: 1`.
- Live enforcement switches and standalone runtime state are omitted from exported settings exactly as before; the importing device's current values remain in place during merge.
- `focusMirrorVpnEnabled` is always written as a boolean, defaulting to `false`.
- Existing `.focusflow` and legacy `.json` files can be opened through `*/*` and validated by the same envelope checks.
- Replacement restore is refused while a focus session is active.
- Historical scheduled tasks whose end time is already past are imported as skipped and are not scheduled.
- Imported historical/resolved tasks are added with alarms skipped; only still-scheduled tasks are passed to the reminder scheduler.

## Deliberate migration flags

- The source's `Platform.OS === "android"` branch is represented by the Android-only `BackupManager`; callers choose the non-Android path outside this repository.
- The source opened the picker inside JS. Pure Kotlin keeps picker launching in Compose `ActivityResultContracts`, so it does not retain a React bridge or an unsafe activity reference.
- Notification channel creation does not recreate `focusday_foreground`, `focusday_block_alert`, `focusday_vpn`, or `task_alarm`; those native-owned channels remain with their current components to avoid changing their importance or alarm behavior.
